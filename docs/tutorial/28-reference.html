Size-States — Container-Queries

Komponenten reagieren via Size-States auf ihre eigene Breite. Defaults aus dem Schema (überschreibbar via Token):

StateDefault-BreiteToken-Override
compact:< 400pxcompact.max: N
regular:400-800pxregular.min: N, regular.max: N
wide:> 800pxwide.min: N
eigeneper Token definiertstatename.min: N / .max: N

Beispiel: 

Card: pad 16, gap 12
  compact:
    pad 8, gap 6, fs 13
  wide:
    pad 24, gap 16, fs 16
