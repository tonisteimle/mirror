Visuelles Editieren

Smart-Guides, Snap, Grid-Mode, Auto-Layout-Inferenz

Über die Basis-Operationen aus Kapitel 18 hinaus hat Studio visuelle Hilfen, die das Bauen schneller machen — Smart-Guides richten Elemente an Nachbarn aus, Snap rastet auf Vielfache von 4, der Grid-Mode lässt dich Rechtecke direkt in Zellen zeichnen, und Layout-Inferenz erkennt wenn du mehrere Elemente in einen Container droppst und schlägt hor oder grid vor.

Smart-Guides & Snap

Während du ein Element draggst oder resizt, zeigen sich blaue Linien sobald die Position einer Kante eines Nachbar-Elements oder des Containers entspricht. Loslassen rastet ein — Frames bauen sich pixelgenau auf, ohne manuelles Korrigieren.

Zusätzlich gibt es ein Snap-Grid auf Vielfache von 4: ein Frame mit Width 167 wird beim Drag zu 168. Wer das umgehen will, hält beim Drag Cmd — dann deaktivieren sich Snap und Smart-Guides für die Dauer der Geste.

Layout-Inferenz — automatisches hor bei Multi-Drop

Droppst du nacheinander mehrere Elemente in einen vertikal ausgerichteten Container (Default), erkennt Studio nach dem zweiten oder dritten Drop, dass die Children nebeneinander stehen sollten, und blendet beim Container einen kleinen Vorschlags-Button ein — z. B. „→ HStack, gap 8". 

// Vorher (drei Buttons in vertikalen Container gedroppt)
Toolbar
  Button "Speichern"
  Button "Abbrechen"
  Button "Hilfe"

// Klick auf den Vorschlag-Button

// Nachher
Toolbar hor, gap 8
  Button "Speichern"
  Button "Abbrechen"
  Button "Hilfe"

Die Inferenz erkennt auch wrap und grid 12 als sinnvolle Vorschläge — je nachdem, wie viele und wie strukturiert die Drops eintreffen.

Drei Drops → Inference-Vorschlag → Klick → hor

Grid-Mode + Draw-Tool

Container mit grid 12 bekommen ein Grid-Overlay: ein 12-spaltiges Raster wird im Preview eingeblendet sobald der Container selektiert ist. Klick auf eine Komponente in der Palette, dann ziehst du ein Rechteck im Container von Zelle A nach Zelle B. Studio schreibt x A, y 1, w (B-A+1), h 1 in die neue Zeile.

Damit baust du Dashboards, Forms oder strukturierte Layouts in der Hälfte der Zeit — du denkst in Zellen und Spannen statt in Pixeln.

Grid-Mode mit Draw-Tool, 3 Frames in Cells

Position-Controls — absolute Positionierung

Standard-Frames sind im Flex-Flow. Für Overlays, Badges oder Decals willst du absolute Positionierung — Studio toggelt das im Property-Panel mit einem Knopf „Frei positionieren". Damit erscheint x/y in der Properties-Liste; du kannst per Drag im Preview den Frame frei verschieben, oder direkt Werte eingeben.

Für Overlays über Bilder oder Hero-Sektionen ist der stacked-Container die bessere Wahl — Children ohne x/y stapeln sich in der Mitte, mit x/y kannst du sie relativ positionieren. Studio bietet das im Layout-Mode-Toggle als dritte Option neben Vertical und Horizontal.

Das Prinzip: Studio versucht zu erraten was du baust und gibt dir die passende Hilfe. Wenn du sie nicht willst — Cmd-Hold während Drag, Esc um Inference-Dialoge wegzuklicken. Default ist hilfreich, nicht im Weg.
