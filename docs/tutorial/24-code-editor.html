Code-Editor

Autocomplete, Cmd+P, Cmd+F, F2-Rename

Studio nutzt CodeMirror 6 als Editor — schnell, mit Mirror- Syntax-Highlighting und context-aware Autocomplete. Dazu kommt die übliche IDE-Tastatur: Cmd+P für Datei-Switch und F2 für cross-file Rename. Wer aus VS Code kommt, fühlt sich schnell zurecht.

Autocomplete für Property-Namen

Tippst du in einer Element-Zeile etwas Buchstaben, öffnet Studio nach kurzer Pause eine Liste von Vorschlägen — alle Properties, die mit dem getippten Prefix beginnen. Tab oder Enter akzeptiert; Esc verwirft.

Die Liste ist context-aware: bei Frame siehst du Layout-Properties prominent (hor, gap, center); bei Text dominieren die Typo-Properties (fs, weight, col). Snippets wie pad ${1:16} rasten an Tab-Stopps ein, damit du den Wert direkt nachtippen kannst.

(Video folgt: Autocomplete für Properties)

Autocomplete für Tokens und Component-Slots

Tippst du $, kennt Studio den Property-Kontext und schlägt nur die zur Property passenden Tokens vor — bg $ öffnet eine Liste aller *.bg-Tokens, pad $ öffnet die *.pad-Tokens. Property-Sets ohne Suffix erscheinen überall.

Bei Komponenten-Verwendungen kennt das Autocomplete die Slots der jeweiligen Komponente. Wenn du Card mit Enter abschließt und einrückst, sind in der nächsten Zeile Title, Desc, Footer als Vorschläge da — exakt die Slots, die die Card-Definition bietet.

(Video folgt: Token- und Slot-Autocomplete)

Cmd+P — Quick-Switch zwischen Files

In Multi-File-Projekten öffnet Cmd+P ein Fuzzy-Search-Popup über alle Files: tokens.tok, components.com, screens/login.mir, … Tippe Buchstaben, die im Pfad vorkommen, dann Enter — Studio öffnet das File und springt an die letzte Cursor-Position.

Das Fuzzy-Matching ist sub-string + initialen — tk findet tokens.tok, scrl findet screens/login.mir. ↑/↓ navigiert die Treffer, Esc schließt ohne Wechsel.

(Video folgt: Cmd+P Quick-Switch in Multi-File-Projekt)

F2-Rename — Symbol cross-file umbenennen

Cursor auf einen Komponenten-Namen, einen Token-Namen oder einen Element-Namen (name-Property), dann F2. Studio öffnet eine Inline-Rename-Surface, sucht alle Vorkommen über alle Projekt-Files und benennt sie in einem Schritt um.

Tippe den neuen Namen, Enter bestätigt, Esc bricht ab. Wenn ein Name-Konflikt droht (du willst etwas in einen Namen umbenennen, der schon existiert), warnt Studio bevor es ausführt.

Das Prinzip: Die Editor-Tastatur ist VS-Code-kompatibel. Was du in anderen IDEs gewohnt bist, geht hier auch — der Editor ist nicht auf Visual-Editing reduziert.
