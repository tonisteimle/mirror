AI-unterstütztes Bauen

Sketches in Mirror übersetzen, Code mit einer Anweisung ändern

Mirror Studio versteht Sketch-Marker — kleine ---Markierungen im Code, mit denen du der AI sagst: „Das ist nicht-fertiger Mirror, mach was draus." Cmd+Enter (oder ein Klick auf das ✦-Icon in der Editor-Toolbar) löst die Übersetzung aus.

Sketch-Block: vom Pseudocode zur Card

Setze den Cursor an die gewünschte Stelle, schreibe einen Block mit zwei ---Zeilen und kritzel dazwischen frei rein was du willst — Pseudocode, deutsche Sätze, eine Mischung. Beim Cmd+Enter sieht der Status-Indikator oben rechts „Übersetze Sketch…", und die orangen Striche links am Block pulsen, solange die AI antwortet.

Block-Sketch mit drei Zeilen Beschreibung → Frame, drei Text/Button- Children, sauberes Mirror-Layout. Tab akzeptiert.

Der getippte Block sah so aus: 

--
card mit titel willkommen und untertitel "ein neuer bereich"
und einem button loslegen in blau
--

Die AI ersetzt die zwei ---Marker und alles dazwischen durch echten Mirror-Code. Wenn du das nicht möchtest, drückst du Esc statt Tab — der Sketch bleibt erhalten und du formulierst um.

Trailing-Sketch: ein Element gezielt ändern

Wenn du Code schon hast und nur etwas ändern willst, hänge die Anweisung als -- inhalt-Suffix direkt an die Zeile des Elements. Die AI versteht das als „mach das Element davor so".

Trailing-Sketch -- mach grün auf der ersten Card- Zeile. Der amber Streifen markiert den Scope: das ganze Card-Element samt Children. Die zweite Card bleibt unberührt.

Bei Trailing ist das Target deterministisch: immer das Element vor dem --. Wenn das Element Children hat (wie ein Frame mit Text und Button drin), zeigt der dünne linke Streifen den Scope der Anweisung — du siehst sofort, worauf sich „mach grün" bezieht.

Vier Sketch-Formen

Je nachdem wie du gerade tippst, ist mal die eine, mal die andere Form bequemer. Alle vier lösen den gleichen Flow aus — die AI entscheidet selbst, ob sie was Neues erzeugt (Generative) oder bestehenden Code ändert (Imperative).

Was die AI im Hintergrund tut

Beim Cmd+Enter (oder Klick auf das ✦-Icon) bekommt die AI:

  • den vollständigen Code der aktuellen Datei
  • deine Cursor-Position und ggf. Selection
  • was du seit dem letzten AI-Aufruf getippt hast (Diff)
  • alle anderen Files im Projekt (Tokens, Components, Layouts)
  • plus eine prominente Liste der erkannten Sketch-Blocks

Sie antwortet mit einem oder mehreren Search/Replace- Patches. Der Editor zeigt das Resultat als Ghost-Diff: rote Zeilen werden gelöscht, grüne dazugefügt. Du akzeptierst mit Tab, verwirfst mit Esc.
