Pickers

Floating-UI für Farbe, Token, Icon, Animation, Action

Property-Panel-Felder, deren Wert nicht einfach eine Zahl ist, öffnen einen Picker als kleines Floating-Fenster. Studio hat fünf davon — jeder ist auf seinen Werte-Typ optimiert: der Color-Picker zeigt Schwatch-Grids und Hex-Eingabe, der Token-Picker filtert nach Property-Kontext, der Icon-Picker hat eine Suche durch 1000+ Lucide-Icons und so weiter. Alle Pickers sind erreichbar über das Property-Panel oder über Ctrl+Space im Editor.

Color-Picker — Hex-Tab

Klick auf ein Color-Trigger im Property-Panel (bg, col, boc, ic) öffnet den Color-Picker. Der Hex-Tab ist der Default: ein Schwatch-Grid mit kuratierten Standard- Farben, ein freies Hex-Input und ein Eyedropper für Bildschirm-Pick.

Das Schwatch-Grid ist nicht beliebig — die Farben sind die Tailwind-Skala (50/100/200…/900) für 22 Farbtöne. Damit landest du immer auf etablierten Werten und Mirror-Code wird visuell konsistent. Recent-Colors am unteren Rand merken sich die zuletzt im Projekt benutzten Farben.

(Video folgt: Color-Picker Hex-Tab)

Color-Picker — Token-Tab

Im selben Picker steht oben ein zweiter Tab: Tokens. Hier werden die im Projekt definierten Color-Tokens (aus .tok-Files oder oben im aktuellen File) gelistet, jeweils mit ihrem Visual-Schwatch. Klickst du einen Token an, landet $tokenname im Code statt der Hex-Wert.

Der Vorteil ist nicht die Bequemlichkeit beim Auswählen — sondern dass spätere Token-Änderungen alle Verwendungen gleichzeitig anpassen. Ein neues Brand-Blau in einer Zeile umsetzen statt in 47.

(Video folgt: Color-Picker Token-Tab)

Token-Picker

Bei Properties die nicht-Color sind (pad, rad, fs, gap, …) hat das Property-Panel-Feld einen kleinen Token-Trigger neben dem Input. Klick öffnet den Token-Picker — eine gefilterte Liste der Tokens, die zur jeweiligen Property passen.

Das Filtern arbeitet über das Suffix-Matching: ein Token card.rad: 8 matcht jedes Radius-Feld; md.pad: 16 matcht jedes Padding. Tokens ohne Suffix (Property-Sets wie cardstyle:) erscheinen überall, weil sie als Set mehrere Properties auf einmal setzen.

Empty-State: hat das Projekt noch keine Tokens, zeigt der Picker einen Hinweis mit Quick-Action „Token hier definieren" — der Cursor springt in die nächste Definition-Position.

(Video folgt: Token-Picker)

Icon-Picker

Icon "name"-Elemente öffnen über das Content-Property den Icon-Picker. Oben ist eine Suche, darunter ein Visual-Grid: alle 1000+ Lucide-Icons gerendert mit ihrem Namen. Tippst du arrow, filtert der Picker auf alle Icons, deren Namen oder Tags „arrow" enthalten.

Hat das Projekt eine $icons:-Section mit eigenen SVG-Pfaden definiert, hat der Picker einen zweiten Tab Custom. Dort tauchen die projekt-eigenen Icons in derselben Visual-Grid-Form auf — Mischung von Lucide und Custom ist nahtlos.

(Video folgt: Icon-Picker mit Suche)

Animation-Picker

anim-Properties (Animations-Presets) öffnen einen Picker mit allen verfügbaren Presets — fade-in, slide-up, bounce, pulse, shake, spin und etwa 14 weitere. Hover über einen Eintrag triggert das Preset live im Preview-Panel als Vorschau, ohne dass du auswählen musst.

Optional kannst du in einem zweiten Eingabefeld eine Dauer setzen (z. B. 0.3s). Studio schreibt das dann als anim slide-up 0.3s in den Code.

(Video folgt: Animation-Picker mit Live-Preview)

Action-Picker

Action-Properties wie onclick, onkeydown oder die direkten Aktionen (toggle(), show(…), set(…)) öffnen den Action-Picker — eine Liste aller eingebauten Mirror- Actions, gegliedert nach Kategorie (State, Sichtbarkeit, Counter, Toast, Navigation, Clipboard, CRUD).

Wählst du eine Action aus, fragt der Picker nach den nötigen Parametern (Target-Element, Wert, Toast-Text usw.) und schreibt den vollständigen Aufruf in den Code. Damit musst du die Action-Syntax nicht auswendig wissen.

(Video folgt: Action-Picker mit Parameter-Eingabe)

Das Wichtigste

Color-Pickerbg / col / boc / ic Trigger#hex oder $token
Token-PickerToken-Trigger neben numerischen Feldern$tokenname
Icon-PickerContent-Feld auf Icon"icon-name"
Animation-Pickeranim-Propertypreset oder preset 0.3s
Action-PickerEvent-Properties (onclick usw.)action(args)

Das Prinzip: Pickers nehmen dir die Syntax-Last ab. Du wählst aus dem Verfügbaren statt es auswendig zu tippen. Was im Code landet, ist immer gültiger Mirror-Code.
